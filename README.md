# Gps Bulk Button Sender

Gps Bulk Button Sender by Gps Bulk.

## Installation

### Windows
1. Download the latest **`.exe`** installer from the [Releases page](https://github.com/digi-bulk-marketing/gps-bulk/releases/latest).
2. Run the installer and follow the prompts.
3. Launch **Gps Bulk Button Sender** from the Start menu.

## Updates

Download the newest installer from the [Releases page](https://github.com/digi-bulk-marketing/gps-bulk/releases/latest) and reinstall.
